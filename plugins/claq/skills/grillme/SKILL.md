# 仕様徹底確認

## 進行ルール

1. 最初の質問の前に、依頼の文面に引っ張られそうなバイアスや定型の答えを 1 行で挙げる。そのうえで論点（目的・制約・成功条件・非目標）を列挙する
2. 論点ごとに質問し、回答が曖昧なら分岐を掘り下げる
3. コードベースを調べれば確定できる回答は、質問せずに調べてから次へ進む
4. 与えられた前提・常識・スキーマを疑い、怪しい前提は黙って従わずに先に指摘する
5. 各質問に推奨の回答と判断理由を短く添える。両論を並べて終わらせず、根拠のうえで立場を示し、局所最適より全体最適、短期的な解決より長期的な視点を優先する
6. 未解決の論点が残っている間は実行の確定に進まない

## 終了条件

- すべての論点が「決定」または「保留（理由付き）」になっている
- 実行してよいかと次のアクションが一意に決まる
- ユーザーの明示的な承認（「進めて」「OK」等）を得ている
